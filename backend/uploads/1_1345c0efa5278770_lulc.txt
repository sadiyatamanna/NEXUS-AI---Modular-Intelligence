My project is titled “Land Use/Land Cover Change Detection Using Satellite Imagery and Machine Learning.” The main objective of this project is to use machine learning to classify land-cover categories in satellite-image patches and compare the predicted classifications of two images to identify differences. The system is developed using React, TypeScript, and Vite for the frontend, Python and FastAPI for the backend, and TensorFlow/Keras for the machine-learning model. The project uses the Sen2_LULC dataset from Project-AgML, available on Hugging Face. The dataset contains satellite-image patches and corresponding pixel-level segmentation masks, which provide the reference labels required for training a segmentation model. The dataset has approximately 213,758 samples, and the development subset previously prepared for this project contains 2,000 samples: 1,600 for training, 200 for validation, and 200 for testing. The images used by the model have dimensions of 64 × 64 pixels with three RGB channels.

The primary machine-learning algorithm used in the project is U-Net, a convolutional neural network architecture designed for semantic segmentation. Unlike traditional image-classification models that assign one label to an entire image, U-Net predicts a land-cover category for each pixel. Its encoder extracts image features using convolutional layers and pooling operations, while its decoder reconstructs the segmentation output through upsampling and skip connections. The model produces five output classes: Vegetation, Agriculture, Built-up, Water, and Barren/Open. These categories are derived by mapping the original dataset's seven mask labels into five broader classes. The previously recorded model configuration uses TensorFlow/Keras, the Adam optimizer, a learning rate of 0.0001, class-weighted sparse categorical cross-entropy, a batch size of 16, and five training epochs. The recorded architecture has approximately 1.88 million trainable and non-trainable parameters combined, although the current source code should be checked to confirm these details.

The training process uses the training subset to learn model parameters, the validation subset to assess performance during training, and the test subset to evaluate the trained model on unseen samples. The previously recorded evaluation results include 47.26% accuracy, 35.37% macro precision, 41.67% macro recall, 32.23% macro F1-score, and 21.59% mean Intersection over Union (mIoU). These results indicate that the model has learned to classify land-cover patterns but still has considerable room for improvement, particularly for some underrepresented classes. Class weighting was incorporated to give greater importance to less frequent categories, such as Water, during training. These metrics are historical results and should be reproduced or confirmed using the current evaluation code before being presented as the final results of the project.

The project also implements pixel-level change comparison. When two images are supplied, the backend uses the trained U-Net model to generate a predicted segmentation mask for each image. The system compares the two masks pixel by pixel. If the predicted categories at a corresponding pixel differ, that pixel is marked as changed; otherwise, it is marked as unchanged. The change percentage is calculated by dividing the number of changed pixels by the total number of compared pixels and multiplying the result by 100. The application can also present a change map, class-transition counts, and statistics describing the predicted land-cover distribution. This functionality is implemented through the FastAPI backend, with the previously documented comparison endpoint being /api/compare-images. The React frontend provides the interface for uploading images and displaying classification results, change comparisons, and statistics.

The application also includes an interactive image-space land-cover viewer intended to display the original image and its predicted classification mask. However, the RGB dataset used by the current model does not, by itself, provide the spectral information needed to calculate scientifically valid NDVI, nor does an ordinary image patch automatically provide the geographic coordinates and spatial reference information required for a true geographical map. Furthermore, comparing two unrelated dataset samples cannot establish that actual land-cover change occurred at a particular location over time. Therefore, the current implementation should be described as land-cover semantic segmentation and pixel-level comparison of predicted masks, unless the code and input data establish that genuine multi-temporal, georeferenced change detection is supported. The project source code is maintained in a GitHub repository, and its major components include the U-Net architecture, dataset preparation, training, inference, evaluation, FastAPI endpoints, and React frontend. To run the complete application, the backend must be started from the project root using Uvicorn, and the frontend must be started separately using Vite. The dataset and trained model may need to be downloaded or regenerated because large data and model artifacts were excluded from Git tracking.
